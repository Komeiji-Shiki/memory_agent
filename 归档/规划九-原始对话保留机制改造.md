# 📝 原始对话保留机制改造

## 🎯 核心思路

**当前问题**：
```
对话 → 模型总结 → 摘要 → 模型合并 → 日记
         ↑           ↑
       可能发癫    二手信息
```

**改造后**：
```
对话 → 直接保存原始记录 → 需要时才生成日记
         ↓
    完整保留，绝不丢失
```

```
lifebook/pending/
```

**问题**：
1. `（总结）` 是模型生成的，可能遗漏细节
2. 原始对话内容没有保存
3. 如果总结出错，无法恢复

## 🆕 新架构设计

### 存储结构

```
lifebook/
├── conversations/               ← 【新增】原始对话目录
│   ├── 2026-01-21_1224.jsonl   ← JSONL 格式，完整对话
│   ├── 2026-01-21_1850.jsonl
│   └── 2026-01-22_0930.jsonl
│
├── daily/                       ← 日记（由对话生成）
│   └── 2026-01-21.md
│
├── nodes/                       ← 知识节点
└── ...
```

### 对话文件格式 (JSONL)

```jsonl
// conversations/2026-01-21_1224.jsonl
// 文件头（第一行）
{"type": "header", "session_id": "2026-01-21_1224", "start_time": "2026-01-21T12:24:00", "model": "claude-3-5-sonnet", "fingerprint": "sha256:abc123..."}

// 对话内容（每轮一行）
{"type": "turn", "turn_id": 1, "timestamp": "2026-01-21T12:24:15", "user": "你好，今天我们来讨论一下LifeBook的改进", "assistant": "好的主人！我很期待这次讨论...", "model": "claude-3-5-sonnet"}
{"type": "turn", "turn_id": 2, "timestamp": "2026-01-21T12:26:30", "user": "我觉得pending机制需要改进", "assistant": "确实，目前的摘要机制有丢信息的风险..."}
{"type": "turn", "turn_id": 3, "timestamp": "2026-01-21T12:28:45", "user": "不如直接保存原始对话", "assistant": "这是个绝妙的想法！..."}

// 会话元数据（最后一行，会更新）
{"type": "footer", "end_time": "2026-01-21T14:30:00", "turn_count": 15, "total_tokens": 12500, "topics": ["LifeBook改进", "pending机制"]}
```

**为什么用 JSONL**：
- 追加写入高效（每轮对话追加一行）
- 方便流式读取
- 单行损坏不影响整体
- 可以直接 `grep` 搜索

## 🔑 会话匹配机制

### 核心问题：如何判断"同一个对话窗口"？

客户端发来的请求只有 `messages`，没有 session_id。我们需要用**指纹匹配**。

### 匹配策略

```python
class ConversationMatcher:
    """对话匹配器 - 判断是续写还是新建"""
    
    def __init__(self, conversations_dir: Path):
        self.dir = conversations_dir
    
    def match(self, messages: List[Dict]) -> Tuple[Optional[Path], bool]:
        """
        匹配对话文件
        
        Returns:
            (文件路径, 是否新建)
        """
        if len(messages) < 2:
            return self._create_new(), True
        
        # 计算对话指纹（前几轮的哈希）
        fingerprint = self._compute_fingerprint(messages[:5])
        
        # 查找匹配的文件
        for conv_file in self._get_recent_files(hours=24):
            header = self._read_header(conv_file)
            
            # 完全匹配：指纹相同
            if header.get("fingerprint") == fingerprint:
                return conv_file, False
            
            # 前缀匹配：新对话是旧对话的延续
            if self._is_continuation(conv_file, messages):
                return conv_file, False
        
        # 没有匹配，新建
        return self._create_new(), True
    
    def _compute_fingerprint(self, messages: List[Dict]) -> str:
        """计算对话指纹"""
        # 只用前几轮对话的 user 消息计算
        user_messages = [m["content"][:100] for m in messages if m["role"] == "user"]
        content = "|".join(user_messages[:3])
        return hashlib.sha256(content.encode()).hexdigest()[:16]
    
    def _is_continuation(self, conv_file: Path, messages: List[Dict]) -> bool:
        """判断是否是已有对话的延续"""
        existing_turns = self._read_turns(conv_file)
        
        if not existing_turns:
            return False
        
        # 检查新消息的前N轮是否与已有对话匹配
        for i, turn in enumerate(existing_turns):
            if i >= len(messages) - 1:
                break
            
            # 比较 user 消息
            new_msg = messages[i * 2 + 1] if i * 2 + 1 < len(messages) else None
            if new_msg and new_msg.get("role") == "user":
                if new_msg["content"][:100] != turn["user"][:100]:
                    return False
        
        return True
    
    def _get_recent_files(self, hours: int = 24) -> List[Path]:
        """获取最近的对话文件"""
        cutoff = datetime.now() - timedelta(hours=hours)
        files = []
        
        for f in self.dir.glob("*.jsonl"):
            # 从文件名解析时间
            try:
                date_str = f.stem  # "2026-01-21_1224"
                file_time = datetime.strptime(date_str, "%Y-%m-%d_%H%M")
                if file_time >= cutoff:
                    files.append(f)
            except ValueError:
                continue
        
        return sorted(files, key=lambda f: f.stat().st_mtime, reverse=True)
```

## 📝 对话记录器

```python
# memory_store/conversation_logger.py

import json
from pathlib import Path
from datetime import datetime
from typing import Dict, List, Optional
import hashlib

class ConversationLogger:
    """原始对话记录器"""
    
    def __init__(self, lifebook_path: str):
        self.conv_dir = Path(lifebook_path) / "conversations"
        self.conv_dir.mkdir(parents=True, exist_ok=True)
        self.matcher = ConversationMatcher(self.conv_dir)
        
        # 当前会话缓存
        self._current_file: Optional[Path] = None
        self._current_turn: int = 0
    
    def log_turn(
        self,
        messages: List[Dict],
        model: str,
        response: str,
        metadata: Optional[Dict] = None
    ) -> Path:
        """
        记录一轮对话
        
        Args:
            messages: 完整消息历史（包括system）
            model: 使用的模型
            response: AI回复
            metadata: 额外元数据（tokens等）
        
        Returns:
            对话文件路径
        """
        # 1. 匹配或创建文件
        conv_file, is_new = self.matcher.match(messages)
        
        if is_new:
            self._init_new_file(conv_file, messages, model)
            self._current_turn = 0
        
        # 2. 提取当前轮的 user 消息
        # messages 结构: [system, user, assistant, user, assistant, ..., user]
        # 最后一个 user 是当前轮
        current_user = None
        for msg in reversed(messages):
            if msg["role"] == "user":
                current_user = msg["content"]
                break
        
        if not current_user:
            return conv_file
        
        # 3. 追加对话记录
        self._current_turn += 1
        turn_record = {
            "type": "turn",
            "turn_id": self._current_turn,
            "timestamp": datetime.now().isoformat(),
            "user": current_user,
            "assistant": response,
            "model": model
        }
        
        if metadata:
            turn_record["metadata"] = metadata
        
        with open(conv_file, "a", encoding="utf-8") as f:
            f.write(json.dumps(turn_record, ensure_ascii=False) + "\n")
        
        # 4. 更新 footer
        self._update_footer(conv_file)
        
        self._current_file = conv_file
        return conv_file
    
    def _init_new_file(self, conv_file: Path, messages: List[Dict], model: str):
        """初始化新的对话文件"""
        fingerprint = self.matcher._compute_fingerprint(messages)
        
        header = {
            "type": "header",
            "session_id": conv_file.stem,
            "start_time": datetime.now().isoformat(),
            "model": model,
            "fingerprint": fingerprint
        }
        
        # 提取 system prompt（如果有）
        for msg in messages:
            if msg["role"] == "system":
                header["system_prompt_preview"] = msg["content"][:200]
                break
        
        with open(conv_file, "w", encoding="utf-8") as f:
            f.write(json.dumps(header, ensure_ascii=False) + "\n")
    
    def _update_footer(self, conv_file: Path):
        """更新文件尾部元数据"""
        # 读取所有内容
        with open(conv_file, "r", encoding="utf-8") as f:
            lines = f.readlines()
        
        # 移除旧的 footer（如果有）
        if lines and '"type": "footer"' in lines[-1]:
            lines = lines[:-1]
        
        # 统计信息
        turn_count = sum(1 for l in lines if '"type": "turn"' in l)
        
        footer = {
            "type": "footer",
            "end_time": datetime.now().isoformat(),
            "turn_count": turn_count,
            "updated_at": datetime.now().isoformat()
        }
        
        lines.append(json.dumps(footer, ensure_ascii=False) + "\n")
        
        # 写回
        with open(conv_file, "w", encoding="utf-8") as f:
            f.writelines(lines)
    
    def get_conversation(self, session_id: str) -> Optional[Dict]:
        """读取完整对话"""
        conv_file = self.conv_dir / f"{session_id}.jsonl"
        
        if not conv_file.exists():
            return None
        
        result = {
            "header": None,
            "turns": [],
            "footer": None
        }
        
        with open(conv_file, "r", encoding="utf-8") as f:
            for line in f:
                try:
                    record = json.loads(line)
                    if record["type"] == "header":
                        result["header"] = record
                    elif record["type"] == "turn":
                        result["turns"].append(record)
                    elif record["type"] == "footer":
                        result["footer"] = record
                except json.JSONDecodeError:
                    continue
        
        return result
    
    def list_conversations(
        self,
        days: int = 7,
        include_preview: bool = True
    ) -> List[Dict]:
        """列出最近的对话"""
        cutoff = datetime.now() - timedelta(days=days)
        conversations = []
        
        for f in sorted(self.conv_dir.glob("*.jsonl"), reverse=True):
            try:
                date_str = f.stem
                file_time = datetime.strptime(date_str[:10], "%Y-%m-%d")
                
                if file_time.date() < cutoff.date():
                    continue
                
                conv = self.get_conversation(f.stem)
                if conv:
                    info = {
                        "session_id": f.stem,
                        "start_time": conv["header"].get("start_time"),
                        "end_time": conv["footer"].get("end_time") if conv["footer"] else None,
                        "turn_count": len(conv["turns"]),
                        "model": conv["header"].get("model")
                    }
                    
                    if include_preview and conv["turns"]:
                        info["first_message"] = conv["turns"][0]["user"][:100]
                        info["last_message"] = conv["turns"][-1]["assistant"][:100]
                    
                    conversations.append(info)
            except Exception:
                continue
        
        return conversations
```

## 📅 日记生成（按需）

日记不再自动生成，而是**按需生成**：

```python
# memory_store/diary_generator.py

class DiaryGenerator:
    """基于原始对话生成日记"""
    
    def __init__(self, lifebook_path: str, llm_client):
        self.conv_logger = ConversationLogger(lifebook_path)
        self.writer = LifeBookWriter(lifebook_path)
        self.client = llm_client
    
    async def generate_diary(
        self,
        date: str,
        force: bool = False
    ) -> Dict:
        """
        为指定日期生成日记
        
        Args:
            date: 日期 (YYYY-MM-DD)
            force: 是否强制重新生成（即使已存在）
        
        Returns:
            生成结果
        """
        # 1. 收集该日期的所有对话
        conversations = self._get_conversations_for_date(date)
        
        if not conversations:
            return {"success": False, "message": f"{date} 没有对话记录"}
        
        # 2. 检查现有日记
        existing_diary = self.reader.read_diary(date)
        if existing_diary and not force:
            return {"success": False, "message": "日记已存在，使用 force=True 强制重新生成"}
        
        # 3. 组装原始对话内容
        full_content = self._format_conversations(conversations)
        
        # 4. 调用模型生成日记
        prompt = f"""请根据以下原始对话记录，整理成一篇日记。

要求：
1. 用第三人称撰写，称用户为「主人」，AI为「灰魂」
2. 按时间顺序组织
3. 保留重要的细节：人名、项目名、决定、进展
4. 不要遗漏任何可能有价值的信息
5. 可以适当概括，但关键信息必须保留

<原始对话记录>
{full_content}
</原始对话记录>

请生成日记："""
        
        response = await self.client.chat.completions.create(
            model="deepseek-chat",  # 生成日记用便宜的模型就行
            messages=[{"role": "user", "content": prompt}],
            max_tokens=8000
        )
        
        diary_content = response.choices[0].message.content
        
        # 5. 保存日记
        success = self.writer.create_diary(date, diary_content, overwrite=force)
        
        return {
            "success": success,
            "content": diary_content,
            "source_conversations": len(conversations),
            "source_turns": sum(len(c["turns"]) for c in conversations)
        }
    
    def _get_conversations_for_date(self, date: str) -> List[Dict]:
        """获取指定日期的所有对话"""
        conversations = []
        
        for f in self.conv_logger.conv_dir.glob(f"{date}_*.jsonl"):
            conv = self.conv_logger.get_conversation(f.stem)
            if conv and conv["turns"]:
                conversations.append(conv)
        
        # 按时间排序
        conversations.sort(
            key=lambda c: c["header"].get("start_time", "")
        )
        
        return conversations
    
    def _format_conversations(self, conversations: List[Dict]) -> str:
        """格式化对话内容"""
        parts = []
        
        for conv in conversations:
            header = conv["header"]
            parts.append(f"## 对话 {header['session_id']} ({header.get('model', 'unknown')})")
            parts.append(f"开始时间: {header['start_time']}")
            parts.append("")
            
            for turn in conv["turns"]:
                ts = turn.get("timestamp", "")[:16].replace("T", " ")
                parts.append(f"### [{ts}]")
                parts.append(f"**用户**: {turn['user']}")
                parts.append(f"**AI**: {turn['assistant']}")
                parts.append("")
        
        return "\n".join(parts)
```

## 🔄 与 Graphiti 的整合

原始对话 → Graphiti Episode：

```python
# 每轮对话保存后，异步添加到 Graphiti
async def log_and_index(
    self,
    messages: List[Dict],
    model: str,
    response: str
):
    # 1. 保存原始对话
    conv_file = self.logger.log_turn(messages, model, response)
    
    # 2. 异步添加到 Graphiti（用于实时检索）
    if self.graphiti:
        current_user = self._get_last_user_message(messages)
        
        # 组合成 episode
        episode_content = f"用户: {current_user}\nAI: {response}"
        
        await self.graphiti.add_episode(
            name=f"conv:{conv_file.stem}:{self._current_turn}",
            episode_body=episode_content,
            source_description=f"对话 {conv_file.stem}",
            reference_time=datetime.now()
        )
```

这样就实现了：
- **原始对话**：完整保存在 JSONL
- **实时索引**：Graphiti 提供快速检索
- **日记生成**：按需从原始对话生成

## 📊 对比

| 维度 | 当前方案 | 新方案 |
|------|---------|--------|
| 信息保留 | 摘要（二手） | **原始对话（完整）** |
| 丢信息风险 | 高（模型可能遗漏） | **极低** |
| 存储占用 | 较小 | 较大（但存储便宜） |
| 日记生成 | 自动（可能出错） | **按需（可重试）** |
| 会话识别 | 基于时间间隔 | **基于内容指纹** |
| 实时性 | 异步总结 | **实时保存** |
