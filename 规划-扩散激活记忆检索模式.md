# 🧠 扩散激活记忆检索模式 (`-diffuse`)

> ⚠️ 本文档是功能规划稿，不代表当前仓库已经实现该模式。
> 当前实际支持的模式请以 [`MemoryRouter.route()`](memory_router.py:384) 和 [`README.md`](README.md) 为准。
>
> 借鉴 PeroCore 的 PEDSA 算法，用扩散激活替代 `-log` 模式的固定分层记忆注入

## 📊 问题分析

### 当前 `-log` 模式的痛点

```
-log 模式的工作方式：
┌─────────────────────────────────────────────────────────┐
│  System Prompt                                           │
│  + 最近7天日记（完整内容）           ← 常驻，消耗大量 token │
│  + 本月周总结                       ← 常驻，可能不相关     │
│  + 月总结                           ← 常驻                │
│  + 季总结                           ← 常驻                │
│  + 额外挂载内容                     ← 常驻                │
│  = 动辄 10K-50K+ token 的固定上下文                       │
└─────────────────────────────────────────────────────────┘
```

**问题**：
- 🔴 **Token 浪费**：不管用户问什么，都注入全部分层记忆，80%+ 内容与当前话题无关
- 🔴 **孤岛效应**：只能找到"最近N天"范围内的内容，半年前的相关记忆完全不可见
- 🔴 **无联想能力**：无法发现 A→B→C 的逻辑链关系
- 🟡 **上下文膨胀**：固定记忆占用大量窗口，压缩了有效对话空间

### `-diffuse` 模式的优势

```
-diffuse 模式的工作方式：
┌─────────────────────────────────────────────────────────┐
│  用户输入 "主人最近在做什么项目？"                         │
│     │                                                    │
│     ▼ Embedding                                          │
│  向量检索 Top-10 锚点记忆                                 │
│     │                                                    │
│     ▼ PEDSA 扩散（2步，衰减0.7）                          │
│  联想到 50+ 相关记忆节点                                  │
│     │                                                    │
│     ▼ 综合排序（相似度×0.5 + 扩散×0.3 + 重要性×0.15 + 近期×0.05）│
│  精选 Top-K 最相关记忆                                    │
│     │                                                    │
│     ▼ 注入到上下文                                        │
│  = 仅 2K-5K token 的精准记忆                              │
└─────────────────────────────────────────────────────────┘
```

**优势**：
- ✅ **精准检索**：只注入与当前话题相关的记忆，token 利用率极高
- ✅ **跨时间关联**：能发现半年前的相关记忆（只要有关系链）
- ✅ **联想能力**：A→B→C 多跳逻辑穿透
- ✅ **低延迟**：扩散计算 <10ms + embedding API 调用 ~100ms
- ✅ **低成本**：仅 1 次 embedding API 调用（vs `-memory` 模式的多轮 Agent LLM 调用）

## 🏗️ 架构设计

### 模式对比

| 特性 | `-log` | `-memory` | `-diffuse`（新） |
|------|--------|-----------|-----------------|
| 固定分层记忆 | ✅ 全量注入 | ✅ 全量注入 | ❌ 不注入 |
| 检索方式 | 无检索 | Agent LLM 多轮检索 | **PEDSA 扩散激活** |
| 延迟 | ~0ms | 5-30s（LLM调用） | **~100ms**（1次embedding） |
| API 成本 | 0 | 高（Agent调用） | **极低**（1次embedding） |
| 精准度 | 低（全量堆砌） | 高（智能检索） | **中高**（算法检索） |
| 联想能力 | ❌ | ✅（LLM推理） | ✅（图扩散） |
| 后处理总结 | ❌ | 看配置 | ❌（同 log） |

### 数据流

```
                     用户消息
                        │
                        ▼
              ┌─────────────────────┐
              │   Embedding 服务     │  ← 复用现有 RAG embedding API
              │   (文本 → 向量)     │
              └─────────┬───────────┘
                        │ query_vec
                        ▼
              ┌─────────────────────┐
              │   向量检索 (RAG)     │  ← 复用现有 RAGIndex.search()
              │   Top-N 锚点        │     返回 List[Tuple[VectorEntry, float]]
              └─────────┬───────────┘
                        │ anchor_entries + scores
                        ▼
              ┌─────────────────────┐
              │   PEDSA 扩散引擎     │  ← pero-memory-core
              │   CognitiveGraph    │     节点ID: int (str→int映射)
              │   propagate()       │
              └─────────┬───────────┘
                        │ activated_ids + energy
                        ▼
              ┌─────────────────────┐
              │   综合排序 + 格式化   │
              │   Score = Sim×0.5    │
              │   + Activation×0.3   │
              │   + Importance×0.15  │
              │   + Recency×0.05     │
              └─────────┬───────────┘
                        │ top_k memories
                        ▼
              ┌─────────────────────┐
              │  注入到消息上下文     │  ← 复用 ContextBuilder
              └─────────────────────┘
```

```python
# memory_store/diffusion_engine.py

"""
扩散激活记忆引擎
基于 PeroCore 的 PEDSA (Parallel Energy-Decay Spreading Activation) 算法

核心思路：
1. 用向量检索找到 Top-N 锚点（语义最相似的记忆）
2. 从锚点出发，沿知识图谱的关系边扩散能量
3. 能量随距离衰减，最终收集所有被激活的记忆节点
4. 综合排序：语义相似度 + 扩散能量 + 重要性 + 时间衰减

关系图数据来源（替代原规划的 tags 方案）：
- memory_index.db 的 links 表：[[wiki-link]] 节点间关系（112条）
- memory_index.db 的 people 表：共提到相同人物的文件（65条）
- memory_index.db 的 keywords 表：共享高权重关键词（57301条）
- RAG vectors.db：同一来源文件的 chunk 时序链接
- 时间邻近：同一天的不同来源记忆
"""

import math
import re
import logging
import sqlite3
from datetime import datetime
from pathlib import Path
from typing import List, Dict, Any, Optional, Tuple, Set
from dataclasses import dataclass, field
from collections import defaultdict

logger = logging.getLogger(__name__)


@dataclass
class ActivatedMemory:
    """被激活的记忆节点"""
    id: str                    # 记忆ID（VectorEntry 的 hash ID）
    content: str               # 记忆内容
    source: str                # 来源路径（如 daily/2026-01-15.md）
    similarity: float          # 向量相似度（锚点得分，非锚点为0）
    activation_energy: float   # 扩散激活能量
    importance: float          # 重要性（基于类型推断）
    timestamp: Optional[str]   # 时间戳
    final_score: float = 0.0   # 综合得分


@dataclass
class DiffusionConfig:
    """扩散引擎配置"""
    # PEDSA 参数
    diffusion_steps: int = 2          # 扩散步数（逻辑链深度）
    decay_factor: float = 0.7         # 能量衰减系数
    min_threshold: float = 0.05       # 最小能量阈值（低于此值被剪枝）
    max_active_nodes: int = 10000     # 每步最大活跃节点数
    max_fan_out: int = 20             # 每节点最大扩散分支数
    
    # 检索参数
    anchor_count: int = 10            # 向量检索锚点数量
    result_limit: int = 15            # 最终返回结果数
    min_score: float = 0.1            # 最低综合得分
    
    # 排序权重
    similarity_weight: float = 0.5    # 语义相似度权重
    activation_weight: float = 0.3    # 扩散能量权重
    importance_weight: float = 0.15   # 重要性权重
    recency_weight: float = 0.05     # 近期性权重
    
    # 艾宾浩斯衰减参数
    ebbinghaus_rate: float = 0.023    # 衰减率（30天衰减至~50%）
    
    # 关系强度
    temporal_link_strength: float = 0.15   # 时间轴链接（同一来源文件的chunk prev/next）
    same_day_link_strength: float = 0.12   # 同一天不同来源的记忆
    wiki_link_strength: float = 0.5        # [[wiki-link]] 节点间关系（最强）
    people_link_strength: float = 0.35     # 共提到同一人物
    keyword_link_strength: float = 0.2     # 共享高权重关键词

    # 关键词连接参数
    keyword_min_weight: float = 3.0        # 最小关键词权重（过滤低频词）
    keyword_max_group_size: int = 30       # 单个关键词最大连接组（过滤超高频词）


# === 类型 → 重要性默认值 ===
TYPE_IMPORTANCE = {
    "diary": 1.0,
    "node": 2.5,             # 知识节点最重要
    "node_人物": 3.0,        # 人物节点更重要
    "node_概念": 2.0,
    "node_事物": 2.0,
    "node_地点": 1.5,
    "summary_weekly": 0.8,
    "summary_monthly": 0.6,
    "summary_quarterly": 0.5,
}


class DiffusionEngine:
    """
    扩散激活记忆引擎
    
    结合 LifeBook 的存储结构与 PeroCore 的 PEDSA 算法
    
    与原规划的关键区别：
    - 原规划依赖 metadata.tags → 实际无 tags
    - 改用 memory_index.db 的 links/people/keywords 表构建关系图
    - VectorEntry.id 是字符串 → 需要 str↔int 双向映射
    """
    
    def __init__(self, config: DiffusionConfig, lifebook_path: str):
        self.config = config
        self.lifebook_path = Path(lifebook_path)
        self._engine = None
        self._initialized = False
        
        # str↔int ID 双向映射（PEDSA 引擎用 int 节点 ID）
        self._str_to_int: Dict[str, int] = {}
        self._int_to_str: Dict[int, str] = {}
        self._next_int_id: int = 0
        
        # 节点元数据缓存
        self._node_metadata: Dict[str, Dict[str, Any]] = {}  # str_id → metadata
    
    def _get_int_id(self, str_id: str) -> int:
        """获取或分配 int ID（PEDSA 引擎要求 int 节点 ID）"""
        if str_id not in self._str_to_int:
            int_id = self._next_int_id
            self._str_to_int[str_id] = int_id
            self._int_to_str[int_id] = str_id
            self._next_int_id += 1
        return self._str_to_int[str_id]
    
    def _ensure_engine(self):
        """确保 PEDSA 引擎已初始化"""
        if self._engine is not None:
            return
        
        try:
            from pero_memory_core import CognitiveGraphEngine
            
            logger.info("[Diffusion] 初始化 PEDSA 引擎...")
            self._engine = CognitiveGraphEngine()
            # 注意：pero-memory-core 0.2.6 用 configure() 而非构造参数
            self._engine.configure(
                max_active_nodes=self.config.max_active_nodes,
                max_fan_out=self.config.max_fan_out
            )
            logger.info("[Diffusion] PEDSA 引擎就绪")
        except ImportError:
            logger.warning(
                "[Diffusion] pero-memory-core 未安装，"
                "将回退到纯向量检索模式（无扩散）。"
                "安装：pip install pero-memory-core"
            )
            self._engine = False  # 标记为不可用
    
    def build_graph(self, rag_index, memory_index_db_path: str = None) -> int:
        """
        构建扩散关系图
        
        数据源：
        1. RAG vectors.db → 同来源文件的 chunk 时序链 + 同日期连接
        2. memory_index.db → [[wiki-link]] 关系 + 人物共现 + 关键词共现
        
        Args:
            rag_index: RAGIndex 实例
            memory_index_db_path: memory_index.db 路径
        
        Returns:
            建立的连接数
        """
        self._ensure_engine()
        if not self._engine:
            return 0
        
        entries = rag_index.entries  # Dict[str, VectorEntry]
        if not entries:
            return 0
        
        connections: List[Tuple[int, int, float]] = []
        
        # --- Phase 1: RAG 向量层关系 ---
        
        # 按来源文件分组
        source_groups: Dict[str, List[str]] = defaultdict(list)
        # 按日期分组
        date_groups: Dict[str, List[str]] = defaultdict(list)
        
        for str_id, entry in entries.items():
            int_id = self._get_int_id(str_id)
            source = entry.file_path
            meta = entry.metadata or {}
            
            # 缓存元数据
            self._node_metadata[str_id] = {
                "content": entry.content,
                "source": source,
                "type": meta.get("type", ""),
                "date": meta.get("date", ""),
                "name": meta.get("name", ""),
                "importance": TYPE_IMPORTANCE.get(meta.get("type", ""), 1.0),
            }
            
            # 按来源分组
            source_groups[source].append(str_id)
            
            # 按日期分组（从 metadata 或来源路径提取日期）
            date = meta.get("date", "")
            if not date:
                date = self._extract_date(source)
            if date:
                date_groups[date].append(str_id)
        
        # A. 同一来源文件的 chunk 之间（时序链接，双向）
        for source, str_ids in source_groups.items():
            if len(str_ids) < 2:
                continue
            # 按 chunk_index 排序
            str_ids.sort(key=lambda sid: entries[sid].chunk_index)
            for i in range(len(str_ids) - 1):
                a = self._get_int_id(str_ids[i])
                b = self._get_int_id(str_ids[i + 1])
                connections.append((a, b, self.config.temporal_link_strength))
                connections.append((b, a, self.config.temporal_link_strength))
        
        # B. 同一天的不同来源记忆之间
        for date, str_ids in date_groups.items():
            if len(str_ids) < 2:
                continue
            # 只连接不同来源的（避免和 A 重复）
            by_source: Dict[str, List[str]] = defaultdict(list)
            for sid in str_ids:
                by_source[self._node_metadata[sid]["source"]].append(sid)
            
            sources = list(by_source.keys())
            for i in range(len(sources)):
                for j in range(i + 1, len(sources)):
                    # 每对来源取第一个 chunk 相互连接（避免 O(n²) 爆炸）
                    a = self._get_int_id(by_source[sources[i]][0])
                    b = self._get_int_id(by_source[sources[j]][0])
                    connections.append((a, b, self.config.same_day_link_strength))
                    connections.append((b, a, self.config.same_day_link_strength))
        
        # --- Phase 2: memory_index.db 关系层 ---
        
        if memory_index_db_path is None:
            memory_index_db_path = str(self.lifebook_path / ".memory_index.db")
        
        if Path(memory_index_db_path).exists():
            connections += self._build_links_from_memory_index(
                memory_index_db_path, entries
            )
        else:
            logger.warning(f"[Diffusion] memory_index.db 不存在: {memory_index_db_path}")
        
        # --- Phase 3: 注入引擎 ---
        
        if connections:
            self._engine.batch_add_connections(connections)
        
        self._initialized = True
        logger.info(
            f"[Diffusion] 图构建完成: "
            f"{len(entries)} 向量节点, {len(connections)} 连接, "
            f"{len(source_groups)} 来源文件, {len(date_groups)} 天"
        )
        
        return len(connections)
    
    def _build_links_from_memory_index(
        self,
        db_path: str,
        rag_entries: Dict  # str_id → VectorEntry
    ) -> List[Tuple[int, int, float]]:
        """
        从 memory_index.db 提取关系，映射到 RAG chunk ID
        
        memory_index.db 结构：
        - files: id, path, type, date, title, snippet, tags_json
        - links: id, source_file_id, target (文件间 [[wiki-link]] 关系)
        - people: id, name, file_id (文件提到的人物)
        - keywords: id, word, file_id, weight (jieba 关键词+权重)
        
        映射策略：
        memory_index.files.path → 匹配 RAG 的 VectorEntry.file_path
        找到匹配的文件后，将该文件的所有 chunk 都参与连接
        """
        connections: List[Tuple[int, int, float]] = []
        
        try:
            conn = sqlite3.connect(db_path)
            cursor = conn.cursor()
            
            # 构建 file_path → [chunk str_ids] 映射
            path_to_chunks: Dict[str, List[str]] = defaultdict(list)
            for str_id, entry in rag_entries.items():
                path_to_chunks[entry.file_path].append(str_id)
            
            # 构建 memory_index file_id → file_path 映射
            cursor.execute("SELECT id, path FROM files")
            mi_id_to_path: Dict[int, str] = {}
            for row in cursor.fetchall():
                file_id, path = row
                # memory_index 存的可能是完整文件名如 "2026-01-15.md"
                # RAG 存的是 "daily/2026-01-15.md"
                # 需要模糊匹配
                mi_id_to_path[file_id] = path
            
            def find_rag_chunks(mi_path: str) -> List[str]:
                """将 memory_index 的 path 映射到 RAG chunk IDs"""
                # 精确匹配
                if mi_path in path_to_chunks:
                    return path_to_chunks[mi_path]
                # 尝试补全路径
                for rag_path, chunks in path_to_chunks.items():
                    if rag_path.endswith(mi_path) or mi_path.endswith(rag_path):
                        return chunks
                    # 提取文件名比较
                    if Path(rag_path).name == Path(mi_path).name:
                        return chunks
                return []
            
            # === A. [[wiki-link]] 关系 (links 表) ===
            cursor.execute("SELECT source_file_id, target FROM links")
            link_count = 0
            for source_file_id, target in cursor.fetchall():
                source_path = mi_id_to_path.get(source_file_id, "")
                source_chunks = find_rag_chunks(source_path)
                if not source_chunks:
                    continue
                
                # target 是链接名如 "灰魂" → 对应节点文件 "人物-灰魂.md" 或 "概念-灰魂.md"
                target_chunks = []
                for prefix in ["人物-", "概念-", "事物-", "地点-", "事件-", ""]:
                    candidate = f"nodes/{prefix}{target}.md"
                    if candidate in path_to_chunks:
                        target_chunks = path_to_chunks[candidate]
                        break
                
                if not target_chunks:
                    continue
                
                # 连接：source 的第一个 chunk ↔ target 的第一个 chunk
                a = self._get_int_id(source_chunks[0])
                b = self._get_int_id(target_chunks[0])
                connections.append((a, b, self.config.wiki_link_strength))
                connections.append((b, a, self.config.wiki_link_strength))
                link_count += 1
            
            logger.debug(f"[Diffusion] wiki-link 关系: {link_count} 条")
            
            # === B. 人物共现关系 (people 表) ===
            cursor.execute("SELECT name, file_id FROM people")
            people_groups: Dict[str, List[int]] = defaultdict(list)
            for name, file_id in cursor.fetchall():
                people_groups[name].append(file_id)
            
            people_count = 0
            for name, file_ids in people_groups.items():
                if len(file_ids) < 2 or len(file_ids) > 50:  # 跳过只出现1次和超高频的
                    continue
                
                # 将 file_ids 转为 chunk IDs
                chunk_groups = []
                for fid in file_ids:
                    path = mi_id_to_path.get(fid, "")
                    chunks = find_rag_chunks(path)
                    if chunks:
                        chunk_groups.append(chunks[0])  # 取每个文件的第一个 chunk
                
                # 两两连接（限制数量避免爆炸）
                for i in range(min(len(chunk_groups), 15)):
                    for j in range(i + 1, min(len(chunk_groups), 15)):
                        a = self._get_int_id(chunk_groups[i])
                        b = self._get_int_id(chunk_groups[j])
                        connections.append((a, b, self.config.people_link_strength))
                        people_count += 1
            
            logger.debug(f"[Diffusion] 人物共现关系: {people_count} 条")
            
            # === C. 关键词共现关系 (keywords 表) ===
            # 只取高权重关键词，避免连接爆炸
            cursor.execute(
                "SELECT word, file_id FROM keywords WHERE weight >= ?",
                (self.config.keyword_min_weight,)
            )
            keyword_groups: Dict[str, List[int]] = defaultdict(list)
            for word, file_id in cursor.fetchall():
                keyword_groups[word].append(file_id)
            
            keyword_count = 0
            for word, file_ids in keyword_groups.items():
                if len(file_ids) < 2 or len(file_ids) > self.config.keyword_max_group_size:
                    continue
                
                chunk_groups = []
                for fid in file_ids:
                    path = mi_id_to_path.get(fid, "")
                    chunks = find_rag_chunks(path)
                    if chunks:
                        chunk_groups.append(chunks[0])
                
                # 限制连接数
                for i in range(min(len(chunk_groups), 10)):
                    for j in range(i + 1, min(len(chunk_groups), 10)):
                        a = self._get_int_id(chunk_groups[i])
                        b = self._get_int_id(chunk_groups[j])
                        connections.append((a, b, self.config.keyword_link_strength))
                        keyword_count += 1
            
            logger.debug(f"[Diffusion] 关键词共现关系: {keyword_count} 条")
            
            conn.close()
            
        except Exception as e:
            logger.error(f"[Diffusion] 从 memory_index.db 构建关系失败: {e}")
        
        return connections
    
    def search(
        self,
        query: str,
        rag_index,  # RAGIndex 实例
        limit: int = None
    ) -> List[ActivatedMemory]:
        """
        扩散激活检索
        
        1. 向量检索锚点（调用 RAGIndex.search()）
        2. PEDSA 扩散
        3. 综合排序
        
        Args:
            query: 用户查询文本
            rag_index: RAGIndex 实例（直接用其 search 方法）
            limit: 返回数量（None 使用配置默认值）
        
        Returns:
            排序后的激活记忆列表
        """
        limit = limit or self.config.result_limit
        self._ensure_engine()
        
        # === 第1阶段：向量检索锚点 ===
        # RAGIndex.search() 返回 List[Tuple[VectorEntry, float]]
        anchor_results = rag_index.search(
            query,
            top_k=self.config.anchor_count
        )
        
        if not anchor_results:
            logger.debug("[Diffusion] 向量检索无结果")
            return []
        
        # 构建锚点分数映射（str_id → score）
        anchor_scores_str: Dict[str, float] = {}
        for entry, score in anchor_results:
            anchor_scores_str[entry.id] = score
            # 确保锚点在元数据缓存中
            if entry.id not in self._node_metadata:
                meta = entry.metadata or {}
                self._node_metadata[entry.id] = {
                    "content": entry.content,
                    "source": entry.file_path,
                    "type": meta.get("type", ""),
                    "date": meta.get("date", ""),
                    "importance": TYPE_IMPORTANCE.get(meta.get("type", ""), 1.0),
                }
        
        # 转换为 int ID 用于 PEDSA
        anchor_scores_int: Dict[int, float] = {}
        for str_id, score in anchor_scores_str.items():
            int_id = self._get_int_id(str_id)
            anchor_scores_int[int_id] = score
        
        # === 第2阶段：PEDSA 扩散 ===
        if self._engine and self._initialized:
            try:
                activated_int = self._engine.propagate_activation(
                    anchor_scores_int,
                    steps=self.config.diffusion_steps,
                    decay=self.config.decay_factor,
                    min_threshold=self.config.min_threshold
                )
                logger.debug(
                    f"[Diffusion] 扩散完成: "
                    f"{len(anchor_scores_int)} 锚点 → {len(activated_int)} 激活节点"
                )
            except Exception as e:
                logger.warning(f"[Diffusion] 扩散失败: {e}，回退到纯向量检索")
                activated_int = anchor_scores_int
        else:
            # 无引擎，回退到纯向量检索
            activated_int = anchor_scores_int
        
        # int ID → str ID
        activated_scores: Dict[str, float] = {}
        for int_id, energy in activated_int.items():
            str_id = self._int_to_str.get(int_id)
            if str_id:
                activated_scores[str_id] = energy
        
        # === 第3阶段：综合排序 ===
        now_ts = datetime.now().timestamp()
        candidates: List[ActivatedMemory] = []
        
        for str_id, activation_energy in activated_scores.items():
            meta = self._node_metadata.get(str_id)
            if meta is None:
                continue
            
            # 语义相似度（锚点有，扩散节点为0）
            similarity = anchor_scores_str.get(str_id, 0.0)
            
            # 重要性归一化 (0-1)
            importance = min(float(meta.get("importance", 1.0)), 10.0) / 10.0
            
            # 时间衰减（艾宾浩斯）
            time_str = meta.get("date", "")
            decay_factor = self._calculate_decay(time_str, now_ts)
            
            # 近期奖励
            recency_bonus = self._calculate_recency_bonus(time_str, now_ts)
            
            # 综合得分
            final_score = (
                similarity * self.config.similarity_weight
                + activation_energy * self.config.activation_weight
                + importance * self.config.importance_weight * decay_factor
                + recency_bonus * self.config.recency_weight
            )
            
            if final_score >= self.config.min_score:
                candidates.append(ActivatedMemory(
                    id=str_id,
                    content=meta.get("content", ""),
                    source=meta.get("source", ""),
                    similarity=similarity,
                    activation_energy=activation_energy,
                    importance=importance,
                    timestamp=time_str,
                    final_score=final_score,
                ))
        
        # 排序 & 截断
        candidates.sort(key=lambda x: x.final_score, reverse=True)
        results = candidates[:limit]
        
        logger.info(
            f"[Diffusion] 检索完成: query='{query[:30]}...' "
            f"→ {len(anchor_results)} 锚点 "
            f"→ {len(activated_scores)} 激活 "
            f"→ {len(results)} 结果"
        )
        
        return results
    
    def format_context(self, memories: List[ActivatedMemory]) -> str:
        """
        将激活的记忆格式化为上下文文本
        
        与 -log 模式的分层记忆不同，这里按相关度排序，
        每条记忆带来源和时间标注
        """
        if not memories:
            return ""
        
        parts = ["## 🧠 相关记忆（扩散激活检索）\n"]
        
        for i, mem in enumerate(memories, 1):
            source_label = self._format_source(mem.source)
            
            score_info = f"相关度:{mem.final_score:.2f}"
            if mem.activation_energy > 0 and mem.similarity == 0:
                score_info += " 🔗联想"  # 标记通过扩散发现的记忆
            
            content = mem.content.strip()
            if len(content) > 500:
                content = content[:500] + "..."
            
            parts.append(f"### {i}. {source_label} ({score_info})")
            parts.append(content)
            parts.append("")
        
        return "\n".join(parts)
    
    def _extract_date(self, source: str) -> Optional[str]:
        """从来源路径中提取日期"""
        match = re.search(r'(\d{4}-\d{2}-\d{2})', source)
        return match.group(1) if match else None
    
    def _calculate_decay(self, time_str: str, now_ts: float) -> float:
        """计算艾宾浩斯时间衰减"""
        if not time_str:
            return 0.5
        try:
            mem_ts = datetime.strptime(time_str[:10], "%Y-%m-%d").timestamp()
            days_passed = max(0, (now_ts - mem_ts) / 86400)
            return math.exp(-self.config.ebbinghaus_rate * days_passed)
        except (ValueError, TypeError):
            return 0.5
    
    def _calculate_recency_bonus(self, time_str: str, now_ts: float) -> float:
        """计算近期性奖励（24小时内线性衰减）"""
        if not time_str:
            return 0.0
        try:
            mem_ts = datetime.strptime(time_str[:10], "%Y-%m-%d").timestamp()
            days_passed = max(0, (now_ts - mem_ts) / 86400)
            if days_passed < 1.0:
                return 0.2 * (1 - days_passed)
            return 0.0
        except (ValueError, TypeError):
            return 0.0
    
    def _format_source(self, source: str) -> str:
        """格式化来源标签"""
        if "daily/" in source:
            date = self._extract_date(source)
            return f"📅 日记 {date}" if date else "📅 日记"
        elif "nodes/" in source:
            name = Path(source).stem
            return f"📌 {name}"
        elif "weekly/" in source:
            return "📋 周总结"
        elif "monthly/" in source:
            return "📊 月总结"
        elif "quarterly/" in source:
            return "📈 季总结"
        else:
            return f"📄 {Path(source).stem}"
    
    def add_connection(self, source_str_id: str, target_str_id: str, strength: float):
        """动态添加连接（用于增量更新）"""
        self._ensure_engine()
        if self._engine:
            a = self._get_int_id(source_str_id)
            b = self._get_int_id(target_str_id)
            self._engine.batch_add_connections([(a, b, strength)])
    
    def get_stats(self) -> Dict[str, Any]:
        """获取引擎统计"""
        return {
            "initialized": self._initialized,
            "engine_available": bool(self._engine),
            "cached_nodes": len(self._node_metadata),
            "id_mapping_size": len(self._str_to_int),
        }
```

```python
def process_diffuse_request(
    self,
    messages: List[Dict[str, Any]],
    route_result: RouteResult,
) -> Tuple[List[Dict[str, Any]], List[Dict[str, Any]]]:
    """
    处理扩散激活检索请求
    
    特点：
    - 不注入固定分层记忆
    - 用 PEDSA 扩散激活检索相关记忆
    - 精准注入到上下文
    - 延迟 ~100ms（1次embedding），低 API 成本
    """
    # 提取查询
    query = self._extract_query(messages)
    
    if not query or not self._is_search_needed(query):
        # 不需要检索，直接透传（只挂载 extra_mount）
        built = self.context_builder.build(
            messages=messages,
            dynamic_memory="",
            include_fixed=False,  # 不包含固定分层记忆！
            model_name=route_result.base_model
        )
        return built.messages, []
    
    # 确保 RAG 索引可用
    if not self.rag_index:
        logging.warning("[Diffuse] RAG 索引不可用，回退到无记忆透传")
        built = self.context_builder.build(
            messages=messages,
            dynamic_memory="",
            include_fixed=False,
            model_name=route_result.base_model
        )
        return built.messages, []
    
    # 确保扩散图已构建
    engine = self.diffusion_engine
    if engine and not engine._initialized:
        import os
        memory_index_path = os.path.join(self.lifebook_path, ".memory_index.db")
        engine.build_graph(self.rag_index, memory_index_path)
    
    # 执行扩散检索
    activated = engine.search(query, self.rag_index)
    diffuse_context = engine.format_context(activated)
    
    # 注入到上下文（使用 dynamic_memory 注入，不用固定记忆）
    built = self.context_builder.build(
        messages=messages,
        dynamic_memory=diffuse_context,
        include_fixed=False,  # 关键：不包含固定分层记忆
        model_name=route_result.base_model
    )
    
    # 更新上次交互时间
    self.metadata_manager.update_last_interaction()
    
    return built.messages, []
```

| 同日期不同来源 | RAG vectors | ~按天 | 0.12 | 同一天不同文件的记忆关联 |

### RAG VectorEntry 结构

```python
@dataclass
class VectorEntry:
    id: str              # md5 hash 字符串（如 "6380f8cb86a3cd40"）
    file_path: str       # 相对路径（如 "daily/2026-01-15.md"）
    chunk_index: int     # 块索引
    content: str         # 原始文本
    metadata: Dict       # {"type": "diary", "date": "2026-01-15"}
                         # 或 {"type": "node_人物", "name": "灰魂"}
                         # ⚠️ 没有 tags 字段！没有 importance 字段！
    embedding: List[float]
    created_at: str

# RAGIndex.search() 返回类型：
List[Tuple[VectorEntry, float]]  # [(entry, similarity_score), ...]

# RAGIndex.entries 属性：
Dict[str, VectorEntry]  # {id → entry}
```
